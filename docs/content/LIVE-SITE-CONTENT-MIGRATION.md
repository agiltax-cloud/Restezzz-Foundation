# Rest Ezzz — Live Site Content Migration & Integration Plan

## Goal
The restored live website is a first-party source that must be preserved and mined for authentic content.

The new site must integrate useful live content into the new strategy rather than:
- cloning the current site
- deleting the old identity
- treating every current promise as operationally verified

## Workflow

```text
CURRENT LIVE SITE
      ↓
SNAPSHOT + PRESERVE
      ↓
CLASSIFY EVERY CONTENT BLOCK
      ↓
KEEP | ADAPT | MERGE | ARCHIVE | RETIRE
      ↓
MAP INTO INTEGRATED IA
      ↓
VERIFY OPERATIONAL CLAIMS
      ↓
EDIT / APPROVE
      ↓
MIGRATE
      ↓
REDIRECT OLD URL
```
