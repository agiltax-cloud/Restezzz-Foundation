- custom WordPress theme
- Gutenberg-first
- GiveWP retained
- no Avada dependency
- responsive images

- XML sitemap
- redirects
- accessibility implementation
- privacy notices

## Explicitly out of scope at launch
- global site search
- blog/journal
- newsletter
- document uploads
- case-status portal
- mentor matching platform
- CRM-driven client portal
- public recipient nomination form
- custom donor portal beyond GiveWP
- autoplay carousel
- parallax effects

## Publication gates
The UX is fixed. The following content is simply omitted until verified:
- eligibility rules
- financial amounts
- exact family-relief benefits
- service geography
- insurance claims
- tax/legal wording
- sponsor benefits
- direct-payment details
- medical/educational assistance claims

No placeholder promises are displayed.
